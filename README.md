# README.MD

# O que é backend???
### Backend roda no servidor e também não podemos acessar com o f12, ele gerencia dados invisiveis, ele é o que garante que tudo funcione corretamente

## como o backend conversa com o front?
### Para que os dois consigam conversar o API precisa coletar o dados necessários para passar para o front mostrando somente o necessário

## O que é um API
### API é a interface de programação de aplicações, ele é o mensageiro que leva seu pedido para o sistema e devolve a resposta, sem ele o front-end não conseguiria conversar com o Back-end

## o que é o front-end
### front-end é tudo que conseguimos ver e acessar com f12


## O que é npm??
### npm significa node package manager e serve para gerenciar os pacotes

## O que é o npx??
### npx significa node package execute, ele serve para executar o pacote instalado

## o que é npm i?
### "npm i" sserve para instalar um pacote
#### exemplo: chalk ou nodemon, basta você baixar o pacote e depois instalar ele com o comando "npm i" como por exemplo "npm i chalk" para instalar o chalk, o mesmo serve para o nodemon ou qaulquer outro pacote

## o que é nodemon?
### nodemon é um pacote que ao ser executado faz com que você não precise executa o comando "node" toda hora, facilitando a execução do código no terminal

## o que é o chalk
### chalk é um pacote que permite que vc personalise a fonte das letras por meio do código

#### os pacotes podem ser acessados através do site npm.com, onde voçê pode acessar vários pacotes
